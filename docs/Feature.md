下面按“轻量级图片查看器”的边界来列功能清单，并用 **P0（MVP 必须）/ P1（首个正式版建议）/ P2（后续增强）** 标注优先级。核心原则是：**查看体验优先、文件管理克制、格式支持可插拔、平台分发可用**。

---

### 一、核心查看功能（P0）

| 功能 | 说明 |
| :--- | :--- |
| 打开单张图片 | 通过文件选择对话框打开 |
| 打开文件夹并浏览 | 加载文件夹内受支持的图片列表，按文件名自然排序 |
| 拖拽打开 | 将图片或文件夹拖入窗口打开 |
| 命令行打开 | 支持 `yourapp image.png`、`yourapp ./photos/`，便于系统关联和脚本调用 |
| 适应窗口显示 | Fit-to-window，窗口变化时自动重算 |
| 原始尺寸显示 | 1:1 像素显示 |
| 缩放 | 放大/缩小、滚轮缩放、重置缩放 |
| 平移 | 图片大于视口时拖拽平移，缩放后保持光标锚点体验 |
| 上一张/下一张 | 键盘方向键、按钮或滚轮翻页 |
| 旋转与翻转 | 90° 旋转、水平/垂直翻转，并可重置 |
| EXIF 方向校正 | 解码后按 Orientation 标签自动旋转，保证跨平台一致 |
| 全屏查看 | 进入/退出全屏 |
| 加载状态与错误提示 | 损坏文件、不支持格式、权限不足时给出明确提示，不崩溃 |

---

### 二、格式与解码（P0/P1/P2）

| 功能 | 优先级 | 说明 |
| :--- | :--- | :--- |
| PNG / JPEG / BMP / GIF / WebP / TIFF / ICO | P0 | 通过 `image` crate 覆盖常见格式 |
| SVG | P1 | 轻量查看器可先不做，或作为可选解码后端 |
| GIF / APNG / 动画 WebP 播放 | P1 | 按原生帧率播放，支持暂停/继续 |
| AVIF | P1 | 作为可插拔解码后端 |
| HEIC / HEIF | P1/P2 | 若目标用户含 iPhone 照片则提升到 P1，通过 `heif-oxide` 或 `libheif` 绑定实现 |
| 相机 RAW 嵌入预览 | P2 | 非轻量级必需，可作为后续扩展 |
| 解码后端可插拔 | P1 | 默认走 `image` crate，特殊格式按需加载，避免主包膨胀 |

---

### 三、浏览与导航（P0/P1）

| 功能 | 优先级 | 说明 |
| :--- | :--- | :--- |
| 缩略图条 / 网格 | P1 | 快速定位当前文件夹中的图片 |
| 最近打开记录 | P2 | 轻量查看器可选，需持久化配置 |
| 幻灯片播放 | P2 | 固定间隔自动翻页，可暂停 |
| 多标签或多窗口 | P2 | 轻量级默认单窗口单图即可；多标签会增加状态管理复杂度 |
| 文件变更监视 | P2 | 当前图片被删除/替换时刷新或提示 |

---

### 四、交互与系统集成（P1/P2）

| 功能 | 优先级 | 说明 |
| :--- | :--- | :--- |
| 完整快捷键体系 | P1 | 打开、翻页、缩放、全屏、退出等 |
| 右键/上下文菜单 | P1 | 复制图片、在文件管理器中显示、另存为等 |
| 复制到剪贴板 | P1 | 复制当前图像或文件路径 |
| 另存为 | P2 | 可导出当前旋转/缩放后的图像，或仅复制文件 |
| 删除/重命名 | P2 | 轻量查看器建议默认只读，文件操作需确认，避免误操作 |
| 文件关联 / 桌面入口 | P1 | Linux `.desktop`、Windows 安装程序注册、macOS 通过打开方式 |
| 深色/浅色主题 | P1 | 跟随系统或手动切换 |
| 国际化 | P2 | 至少中英文可后续补 |

### 五、性能与内存（P0/P1）

| 功能 | 优先级 | 说明 |
| :--- | :--- | :--- |
| GPU 纹理渲染 | P0 | 利用 GPUI 的 GPU 加速路径，避免 CPU 逐像素绘制 |
| 后台解码 | P0 | 解码不阻塞 UI 线程，翻页时保持响应 |
| 相邻图片预加载 | P1 | 预取上一张/下一张，提升翻页体验 |
| 图片缓存上限 | P0 | 按字节预算的 LRU 或视口外纹理释放，防止连续浏览大图导致内存膨胀 |
| 大图降采样/瓦片 | P1/P2 | 超大图先显示低分辨率预览，再按需加载细节；轻量版可先做降采样 |
| 缩略图缓存 | P1 | 磁盘缓存缩略图，避免每次进入文件夹重复解码 |
| 取消加载 | P1 | 快速翻页时取消过期的解码任务 |

### 六、打包、分发与工程（P0/P1）

| 功能 | 优先级 | 说明 |
| :--- | :--- | :--- |
| macOS 未签名 `.app` | P0 | 通过 `gpui-shell bundle` 生成，README 说明右键打开或 `xattr -cr` |
| Windows 便携 `.zip` | P0 | 解压即用；P1 可用 Inno Setup 做安装程序 |
| Linux `.tar.gz` + `install.sh` | P0 | GPUI Kit 默认产物 |
| Linux `.deb` | P1 | 基于 bundle 产物组装或 `cargo-deb` |
| AppImage | P1/P2 | 用 `appimagetool` 组合打包，作为通用 Linux 分发补充 |
| GitHub Actions 矩阵构建 | P0 | macOS / Ubuntu / Windows 原生 runner 分别构建打包 |
| 版本号与 Release 产物 | P0 | 打 tag 自动生成 Release，附带各平台产物和校验和 |
| 日志与崩溃信息 | P1 | 本地日志文件，便于开源用户反馈问题 |
| 配置持久化 | P1 | 窗口大小、主题、缩放偏好等 |

### 七、明确的轻量级边界（建议不做或延后）

- **不做图片编辑**：裁剪、调色、滤镜、批处理不属于查看器核心。
- **不做图库管理**：标签、评分、人脸识别、云同步延后。
- **不做网络功能**：在线图床、分享链接、自动更新可后续再议。
- **不做复杂多文档界面**：首版单窗口单图 + 文件夹浏览即可。
- **不强制签名/公证**：开源阶段通过文档引导用户绕过 Gatekeeper，不纳入功能清单。

---

### 建议的 MVP 验收闭环

首版只要跑通这条链路即可发布：**打开文件夹 → 缩略图/列表浏览 → 适应窗口/缩放/平移 → 上一张/下一张 → EXIF 方向正确 → GIF 可播放 → 内存不随翻页持续增长 → macOS/Windows/Linux 三平台 CI 产物可下载运行**。其余功能按 P1/P2 迭代。
