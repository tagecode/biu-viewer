# 博览(BiuViewer)产品需求文档

## 一、产品概述

### 1.1 产品定位

博览(BiuViewer)是一款跨平台轻量级图片查看器,采用 Rust + GPUI-Kit 技术栈开发,专注于提供流畅、高效的图片浏览体验。产品定位为"轻量级查看器",核心原则是:**查看体验优先、文件管理克制、格式支持可插拔、平台分发可用**。

### 1.2 目标平台

- macOS (10.15+)
- Windows (10/11)
- Linux (主流发行版)

### 1.3 技术架构

- 核心语言: Rust
- UI 框架: GPUI-Kit
- 图像解码: image crate + 可插拔解码后端
- 渲染方式: GPU 纹理加速渲染

## 二、功能需求

### 2.1 核心查看功能 (P0 - MVP必须)

#### 2.1.1 文件打开

- **打开单张图片**: 支持通过文件选择对话框打开单张图片
- **打开文件夹**: 加载文件夹内所有受支持的图片,按文件名自然排序
- **拖拽打开**: 支持拖拽图片文件或文件夹到窗口直接打开
- **命令行打开**:
  - 支持 `biuviewer image.png` 打开单张图片
  - 支持 `biuviewer ./photos/` 打开文件夹
  - 便于系统文件关联和脚本调用

#### 2.1.2 图片显示与操作

- **适应窗口显示**:
  - 自动计算适合窗口的缩放比例(Fit-to-window)
  - 窗口尺寸变化时自动重新计算
- **原始尺寸显示**: 1:1 像素显示,不进行任何缩放
- **缩放功能**:
  - 放大/缩小
  - 鼠标滚轮缩放
  - 重置缩放到默认状态
- **平移功能**:
  - 当图片大于视口时支持拖拽平移
  - 缩放后保持光标锚点位置,提供流畅的缩放体验

#### 2.1.3 图片浏览

- **上一张/下一张**:
  - 键盘方向键(左/右)翻页
  - UI 按钮翻页
  - 支持鼠标滚轮翻页(可选)
- **旋转与翻转**:
  - 90° 旋转(顺时针/逆时针)
  - 水平翻转
  - 垂直翻转
  - 重置所有变换
- **EXIF 方向校正**: 自动读取并应用 EXIF Orientation 标签,确保跨平台显示一致性

#### 2.1.4 显示模式

- **全屏查看**:
  - 进入全屏模式(隐藏标题栏和工具栏)
  - 退出全屏模式
  - 全屏状态下仍可进行所有基本操作

#### 2.1.5 异常处理

- **加载状态提示**: 显示图片加载进度和状态
- **错误提示**:
  - 损坏文件:明确提示文件损坏
  - 不支持格式:提示格式不支持,列出支持的格式
  - 权限不足:提示无法访问文件
  - 所有异常情况下应用不崩溃,给出友好提示

### 2.2 格式与解码支持

#### 2.2.1 基础格式支持 (P0 - MVP必须)

通过 `image` crate 支持以下常见格式:

- PNG
- JPEG/JPG
- BMP
- GIF (静态)
- WebP (静态)
- TIFF
- ICO

#### 2.2.2 动画格式支持 (P1 - 首个正式版)

- **GIF 动画播放**:
  - 按原生帧率播放
  - 支持暂停/继续
  - 显示当前帧/总帧数
- **APNG 播放**: 支持动态 PNG 格式
- **动画 WebP 播放**: 支持动态 WebP 格式

#### 2.2.3 现代格式支持 (P1 - 首个正式版)

- **AVIF**: 作为可插拔解码后端支持
- **SVG**: 轻量查看器可先不做,或作为可选解码后端

#### 2.2.4 专业格式支持 (P1/P2 - 按需实现)

- **HEIC/HEIF** (P1/P2):
  - 若目标用户包含 iPhone 照片用户则优先级提升到 P1
  - 通过 `heif-oxide` 或 `libheif` 绑定实现
- **相机 RAW 嵌入预览** (P2):
  - 非轻量级必需功能
  - 可作为后续扩展

#### 2.2.5 解码架构 (P1)

- **解码后端可插拔**:
  - 默认使用 `image` crate
  - 特殊格式按需加载解码器
  - 避免主程序包体积膨胀

### 2.3 浏览与导航功能

#### 2.3.1 缩略图浏览 (P1 - 首个正式版)

- **缩略图条**:
  - 在窗口底部或侧边显示当前文件夹内所有图片的缩略图
  - 点击缩略图快速跳转
  - 高亮显示当前图片
- **网格视图**:
  - 可选的网格布局浏览模式
  - 支持动态调整缩略图大小

#### 2.3.2 高级浏览功能 (P2 - 后续增强)

- **最近打开记录**: 记录最近打开的文件和文件夹,快速访问
- **幻灯片播放**:
  - 固定时间间隔自动翻页
  - 支持暂停/继续/停止
  - 可配置间隔时间
- **多标签或多窗口**: 支持同时查看多个图片或文件夹
- **文件变更监视**:
  - 监听当前图片的文件系统变化
  - 图片被删除时自动跳转到下一张并提示
  - 图片被修改时自动刷新

### 2.4 交互与系统集成

#### 2.4.1 快捷键体系 (P1 - 首个正式版)

完整的键盘快捷键支持:

- 打开文件/文件夹
- 上一张/下一张(方向键)
- 缩放操作(+/-/0)
- 旋转操作
- 全屏切换(F11 或 F)
- 退出(ESC 或 Q)
- 复制(Ctrl/Cmd+C)
- 删除文件(Del,需确认)

#### 2.4.2 右键菜单 (P1 - 首个正式版)

上下文菜单功能:

- 复制图片到剪贴板
- 复制文件路径
- 在文件管理器中显示
- 另存为
- 删除文件(需确认)
- 重命名(可选)
- 属性信息

#### 2.4.3 剪贴板操作 (P1 - 首个正式版)

- **复制图片**: 将当前图像内容复制到剪贴板
- **复制路径**: 复制当前文件的完整路径

#### 2.4.4 文件操作 (P2 - 后续增强)

- **另存为**:
  - 可导出当前旋转/缩放后的图像
  - 或仅复制原始文件
- **删除文件**:
  - 轻量查看器建议默认只读
  - 文件删除需二次确认,防止误操作
- **重命名**: 支持直接重命名当前图片

#### 2.4.5 系统集成 (P1 - 首个正式版)

- **文件关联**:
  - Linux: 提供 `.desktop` 文件
  - Windows: 安装程序注册文件关联
  - macOS: 通过"打开方式"关联图片格式
- **桌面入口**:
  - 应用图标和快捷方式
  - 支持从系统启动器启动

#### 2.4.6 主题支持 (P1 - 首个正式版)

- **深色/浅色主题**:
  - 跟随系统主题自动切换
  - 支持手动切换
- **主题切换流畅**: 无闪烁切换

#### 2.4.7 国际化 (P2 - 后续增强)

- 至少支持中文(简体)和英文
- 界面文本可本地化
- 日期格式本地化

### 2.5 性能与内存优化

#### 2.5.1 渲染性能 (P0 - MVP必须)

- **GPU 纹理渲染**:
  - 利用 GPUI 的 GPU 加速路径
  - 避免 CPU 逐像素绘制
  - 保证流畅的缩放和平移体验

#### 2.5.2 异步处理 (P0 - MVP必须)

- **后台解码**:
  - 图片解码在后台线程执行
  - 解码过程不阻塞 UI 线程
  - 翻页时保持界面响应

#### 2.5.3 内存管理 (P0 - MVP必须)

- **图片缓存上限**:
  - 基于字节预算的 LRU 缓存策略
  - 视口外纹理及时释放
  - 防止连续浏览大图导致内存膨胀
  - 建议初始缓存上限: 512MB - 1GB

#### 2.5.4 预加载策略 (P1 - 首个正式版)

- **相邻图片预加载**:
  - 后台预加载上一张和下一张图片
  - 提升翻页流畅度
  - 根据内存预算动态调整预加载数量

#### 2.5.5 大图优化 (P1/P2)

- **图片降采样** (P1):
  - 超大图片先显示低分辨率预览
  - 后台加载完整分辨率
  - 避免首次加载卡顿
- **瓦片加载** (P2):
  - 对超大图片(如全景图)按需加载可见区域
  - 支持平滑的平移和缩放

#### 2.5.6 缩略图优化 (P1 - 首个正式版)

- **缩略图缓存**:
  - 磁盘缓存缩略图
  - 避免每次进入文件夹重复解码
  - 定期清理过期缓存

#### 2.5.7 任务管理 (P1 - 首个正式版)

- **取消加载**:
  - 快速翻页时取消过期的解码任务
  - 优先处理当前图片
  - 避免资源浪费

## 三、打包与分发

### 3.1 macOS 平台 (P0 - MVP必须)

- **未签名 .app 包**:
  - 通过 `gpui-shell bundle` 生成
  - README 说明用户如何绕过 Gatekeeper:
    - 右键打开
    - 或使用 `xattr -cr BiuViewer.app` 命令
- **安装方式**: 拖拽到 Applications 文件夹

### 3.2 Windows 平台

- **便携版 .zip** (P0 - MVP必须):
  - 解压即用,无需安装
  - 包含必要的运行时依赖
- **安装程序** (P1 - 首个正式版):
  - 使用 Inno Setup 制作安装程序
  - 支持文件关联和卸载

### 3.3 Linux 平台

- **.tar.gz + install.sh** (P0 - MVP必须):
  - GPUI Kit 默认产物
  - 提供安装脚本自动配置
- **.deb 包** (P1 - 首个正式版):
  - 基于 bundle 产物组装
  - 或使用 `cargo-deb` 生成
  - 支持 apt 安装
- **AppImage** (P1/P2):
  - 使用 `appimagetool` 打包
  - 作为通用 Linux 分发补充
  - 无需安装,直接运行

### 3.4 持续集成 (P0 - MVP必须)

- **GitHub Actions 矩阵构建**:
  - macOS runner 构建 macOS 版本
  - Ubuntu runner 构建 Linux 版本
  - Windows runner 构建 Windows 版本
  - 自动化测试和打包流程

### 3.5 版本管理 (P0 - MVP必须)

- **版本号**: 采用语义化版本(Semantic Versioning)
- **Release 产物**:
  - 打 tag 自动生成 GitHub Release
  - 附带各平台产物和 SHA256 校验和
  - 提供 Release Notes

### 3.6 诊断与反馈 (P1 - 首个正式版)

- **日志系统**:
  - 本地日志文件,便于用户反馈问题
  - 包含错误、警告和关键操作日志
  - 日志文件自动轮转和清理
- **配置持久化**:
  - 保存用户偏好设置:
    - 窗口大小和位置
    - 主题选择
    - 默认缩放模式
    - 快捷键自定义
  - 使用标准配置文件位置:
    - macOS: `~/Library/Application Support/BiuViewer/`
    - Windows: `%APPDATA%\BiuViewer\`
    - Linux: `~/.config/biuviewer/`

## 四、产品边界(明确不做或延后)

### 4.1 不做图片编辑

- 裁剪、调色、滤镜等图片编辑功能不属于查看器核心
- 批处理操作不在产品范围内

### 4.2 不做图库管理

- 标签、评分系统延后
- 人脸识别功能延后
- 云同步功能延后
- 相册/集合管理延后

### 4.3 不做网络功能

- 在线图床集成可后续考虑
- 分享链接功能延后
- 自动更新功能可后续考虑

### 4.4 不做复杂多文档界面

- 首版单窗口单图 + 文件夹浏览即可
- 多标签/多窗口作为 P2 功能

### 4.5 不强制签名/公证

- 开源阶段通过文档引导用户绕过系统限制
- macOS 代码签名和公证不纳入初期功能清单

## 五、MVP 验收标准

### 5.1 功能验收

首版发布需要跑通以下完整链路:

1. **文件打开**:
   - 通过对话框打开文件夹
   - 拖拽文件夹到窗口打开
   - 命令行打开文件夹

2. **图片浏览**:
   - 缩略图条或列表浏览
   - 点击缩略图切换图片
   - 键盘方向键切换上一张/下一张

3. **图片显示**:
   - 适应窗口显示(Fit-to-window)
   - 缩放操作(放大/缩小/重置)
   - 平移操作(拖拽移动)

4. **图片校正**:
   - EXIF 方向自动校正
   - 显示方向正确

5. **动画支持**:
   - GIF 动画可正常播放
   - 帧率正确

6. **性能要求**:
   - 内存不随翻页持续增长
   - 大图加载不卡顿
   - 缩放平移流畅(60fps)

7. **跨平台支持**:
   - macOS 可下载运行
   - Windows 可下载运行
   - Linux 可下载运行
   - 三平台 CI 自动构建成功

### 5.2 质量验收

- 核心功能无阻断性 Bug
- 常见格式(PNG/JPEG/GIF)支持完善
- 异常情况有友好提示,不崩溃
- 基本性能指标达标:
  - 1000 张图片文件夹加载时间 < 3s
  - 单张 10MB 图片加载时间 < 1s
  - 翻页响应时间 < 100ms
  - 内存占用基线 < 200MB

### 5.3 文档验收

- README 包含安装和使用说明
- 各平台特殊说明完整
- 支持的格式列表清晰
- 已知问题和限制说明
